This project is a simple CLI-based base converter. The goal was to build a small tool that can take a number in one base and convert it into another, while also practicing string handling, user input, and number parsing.

The program supports three number bases:

Binary (bin)
Decimal (dec)
Hexadecimal (hex)

how this my projects works..

When the program runs, it prompts the user to enter:

A value to convert
The base of that value

Based on the selected base:

If the input is hex or binary, the program converts it to decimal
If the input is decimal, it converts it into both binary and hexadecimal
